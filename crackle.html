C.R.A.C.K.L.E.

A 30-lb mobile manipulation robot with custom hardware and LLM-driven autonomy.

30-lb mobile robot · CIM-motor tank drivetrain · ESP32 · Robotic arm · Custom gearbox and gripper · Autonomous navigation

The project

C.R.A.C.K.L.E. is a mobile manipulation robot built for an ECLAIR engineering project showcase. It combines a tank drivetrain with an arm and a software architecture designed to grow new capabilities as it operates.

The team earned first place for both “Best Overall” and “Best Acronym” among six engineering projects.

My contributions

  • Developed an LLM-based architecture that can generate new robot capabilities at runtime.
  • Designed custom gearboxes using CAD, 3D printing, and laser cutting, reducing drivetrain current from 133 A to under 25 A.
  • Built a custom C++ drivetrain API and integrated electronics through soldering and system-level wiring.
