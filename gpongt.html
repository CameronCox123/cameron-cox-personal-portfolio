GPongT.

An AI-powered Pong game that generates new levels and challenges at runtime.

AI-assisted code generation · Pong · Runtime feature generation · HackTX 2024

The Idea

Have you ever been bored playing your favorite video game and just wanted something new? Well, you'd better hope it's still supported, or you're going to be fresh out of content... forever!!! Introducing GPongT, a game with a self-evolving codebase, so you never run out of new features to experiment with!.

GPongT combines a Pong game with an AI-based code-generation system. The system analyzes the current codebase and generates supporting features at runtime. In GPongT, it creates new game challenges, object behaviors, and physics effects. The project won first place for “Best AI Hack” at HackTX 2024, among 5,000 participants.

The project documentation is hosted on the Devpost website.

I designed the code-analyzation and generation architecture and integrated it into the game so generated level features could run in a subprocess thread.
