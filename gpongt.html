GPongT.

An AI-powered Pong game that generates new levels and challenges at runtime.

AI-assisted code generation · Pong · Runtime feature generation · HackTX 2024

The project

GPongT combines a Pong game with an AI-based code-generation system. The system analyzes a codebase and generates supporting features at runtime; in GPongT, it creates new game levels and challenges.

The project won first place for “Best AI Hack” at HackTX 2024, among 5,000 participants.

My contribution

I designed the code-generation architecture and integrated it into the game so generated level features could run in a subprocess thread.
